# Canon Ledger — *The Blood Code*

The anti-retcon file. Before any drafting session invents a fact, it checks here.

**Authority order:**

1. `reference/source-bible-v1.md` — the author's original document. Wins everything.
2. **Tier 2** below — decisions that resolve the source's own open questions (source §22).
3. **Tier 3** below — inferences filling gaps the source left silent.
4. Everything else in `series/`, `craft/`, and `books/`.

A later book may not contradict a higher tier. If it must, that's an **override**: log it in §7 with a date and a reason, and update every affected file in the same pass.

## 4. Never-contradict list

The short brutal version. Any draft breaking one of these is wrong, however good the scene is.

1. **Hypnosis cannot manufacture desire.** Not "struggles to." Cannot. Stated plainly once, early, in Lucian's narration.
2. **Selene's blood does not remove Lucian's agency.** Overwhelming, never compelling. The moment it compels, this stops being a romance.
3. **Juliette was guilty.** Not framed, not manipulated, not sorry. If she's innocent, Aurelian is a monster, Cassian is right, and the book collapses.
4. **Cassian chose.** Verity found the grief; it did not install it. His last line carries both halves.
5. **Cassian's grief is genuine.** It's why Lucian can't smell the lie. The warmth is not an act.
6. **Cassian's critique of the Code has real weight.** A villain whose argument is stupid isn't frightening.
7. **Neither species is the moral one.** If wolves start reading as earthy and honest while vampires read as decadent and false, that's drift.
8. **Aurelian was right.** About everything except one friend. Lucian's arc is separating the philosophy from the judgment.
9. **Selene never shifts.**
10. **Nobody asks why neither species will leave New Orleans.** The setup is an absence.
11. **"Verity" is spoken once in Book 1** — Cassian, dying.
12. **Bloodsteel gets three sentences.** No magic system.
13. **Every character in every sexual situation is an adult, with their age in their sheet.**
14. **No narrator gets a measurement system.** Banned as metaphor across all narrators: *arithmetic*, *math*, *load-bearing*, *file/filed/filing* as a cognitive verb, *pricing* as a way of assessing people.
