# Banned Phrases — *The Blood Code*

Every phrase in §1–§5 was counted against **485,000 words** of Kent across four books and came back zero or near-zero. Counts are in parentheses. If one shows up in a draft, it came from the model, not from the genre.

§6 is the opposite list and matters just as much: phrases that *read* as slop but are Kent's actual voice. Banning on instinct would sand her off.

**Authority:** `.claude/CLAUDE.md`. This file is the working instrument — the same lists with the scanner attached.

## 7. Do NOT strip — Kent uses these constantly

This list exists because banning on instinct would have removed her real voice.

**Connective and hedging:** and yet (47) · somehow (51) · a part of me (17) · a mixture of (9) · a beat (25 — mostly *heart skips a beat* and *watches me for a beat*).

**Contemporary vocabulary:** toxic (24) · processing (22) · boundaries (7). Fine in young characters' heads and mouths. Slop *only* as detached narration.

**Genre-native body beats:** shiver (34) · arousal (27) · folds (23) · breath hitched (9) · heart hammered (9) · heart pounded (8) · butterflies (7) · jaw ticked (3). Leave them alone.

**One-owner phrases:** *here's the thing* (5) — but it belongs to Yulian in *Hunt the Villain* as a personal tic. One narrator can own a phrase; nobody else gets it. In our manuscript that slot is filled by Lucian's *"Say it again,"* Selene's *"In wolf, that means—,"* Cassian's *"How is your mother's house?"*, Rémy's *"Yeah, no,"* and Ondine's spoken *"That'll cost."*

## 8. AI voice-system tics — the words a model reaches for when handed a metaphor instruction

The most dangerous category, because these arrive *because* of a good instruction.

| Word | Status | Count in 485K |
|---|---|---|
| **arithmetic** | BANNED | 0. A model told "he thinks in business" will use this 30+ times |
| **math** *(as metaphor)* | BANNED | 0. Same pattern in a different coat |
| **load-bearing** *(as metaphor)* | BANNED | 0. Permitted only in literal structural-engineering dialogue |
| **file / filed / filing** *(as a cognitive verb)* | BANNED | *I file it*, *filed behind his eyes* — cut entirely. The observation stands without naming the cognitive operation |
| **pricing** *(as assessing people)* | max 2 per manuscript | Not 20 |

**The rule:** if you catch yourself reaching for the same metaphor word you used before, that's the model talking, not the character. Vary or cut.

### 8a. Project-specific signature words — ceilings per book

Each narrator's cognitive system has one or two words a model will over-index on. Same failure as *arithmetic*, arriving through our own `VOICE_BIBLE.md`. Ceilings across a whole 95,000-word book:

| Narrator | System | Watch words | Ceiling |
|---|---|---|---|
| Lucian | thresholds and doors | door, threshold, key, lock, unlocked | **~25 total**, and the system must surface as *permission* more often than as a literal door |
| Selene | translation | translate, language, word for, in wolf | **~20 total**, her spoken tic included |
| Cassian | inheritance and debt | owe, owed, inherit, leave behind | **~15 total** across five interstitials |
| Silas | sign and trail | trail, sign, passed through | ~20 (Book 2) |
| Ondine | substitution | substitute, stands in for, spoils | ~20 (Book 2) |
| Rémy | water and draft | tide, aground, floats, draft | ~20 (Book 3) |
| Isabeau | tuning | in tune, flat, half-step | ~15 (Book 3) |

A system is working when the reader feels the pattern and cannot quote the word. If Lucian says *door* forty times, the instrument has become the tic.

### 8b. Construction tics — measured 2026-09-25, book-level ceilings

v1 of Book 1 ran these at 3–50× the rate of every comp on disk. They're model signatures, not voice. `audit.py --book` enforces them. Rates are per 100k words.

| Construction | Comps | Ceiling | Usual fix |
|---|---|---|---|
| *Not X. Y.* (corrective fragment) | 16–34 | **40** | delete the *Not X.* half |
| *isn't X. It's Y* | 4–5 | 10 | state Y |
| *the way …* (simile) | 40–48 | **80** | say the thing, or show the action |
| *the thing* | 2–3 | **10** | name it |
| *which is / which means* | 7–15 | 20 | split or cut |
| *something* | 111–114 | 150 | the specific noun |
| *hands* | 220–297 | 320 | a different body part, or none |
| *copper* (blood smell) | 0–2 | 4 | rust, pennies, salt, iron, a battery on the tongue |
| *damn* | 25 | 30 | a real swear, or nothing |
| *quiet* | 24–40 | 50 | the sound that stopped |

**The brand exception:** *ghost* as Lucian's address term is supposed to repeat (40–60). That's a brand, like *little mouse* (171 uses across the Adeline duet). The difference between a brand and a tic: a brand is a *name* the reader waits for; a tic is a *construction* the reader stops seeing.

**The other half of the trap:** the system must surface as **judgment, not measurement**. Told *doors*, a model builds a floor plan. See `STYLE_GUIDE.md` §6.

## 9. Structural slop — no regex catches these

They matter more than every phrase above. Read for them by hand.

- **Both POVs sounding identical.** The number-one AI tell in dual POV. Run the swap test (`series/VOICE_BIBLE.md` §5).
- **Emotional over-articulation.** A narrator who accurately diagnoses their own psychology is writing an essay. Dark romance leads misread themselves.
- **Naming the feeling right after showing it.** *My hands shook. I was terrified.* Cut the second sentence, always.
- **Symmetrical sex choreography.** *Then he… then she… then he.* Real scenes are lopsided — one person driving, the other reacting.
- **Consent negotiated in clinical language mid-scene.** This project runs dubcon and non-con. A modern checklist mid-scene destroys the register. Consent work lives in framing and aftermath.
- **Overapplying the fragment rhythm.** ~14 runs per chapter across ~50 paragraphs, 69% of them sentence-plus-*one*. Plenty of chapters carry zero parallel triplets.
- **Every chapter ending on a one-line zinger.** 52% of final paragraphs are ≤10 words. Half, not all.
- **Abstract tricolons.** *It was rage, and grief, and something like love.* One concrete image instead.
- **Explaining the metaphor after making it.**
- **Uniform eloquence.** Villains, young wolves, and court functionaries do not share a vocabulary ceiling.
- **Theme stated in dialogue.** Nobody summarizes what the book was about.
- **The villain as professor.** Cassian-specific and the biggest risk in Book 1. An interstitial that explains a strategy gets rewritten as a choice.

## 10. Scanner

PowerShell 5.1. Run from the project root.

```powershell
$file = "books\book-1-king-of-teeth\drafts\ch01.md"

$literal = @(
  "couldn't help but","a mix of","something shifted","spoke volumes","a testament to",
  "hung heavy","crackled with","whirlwind of","raw vulnerability","the weight of his gaze",
  "a silent understanding","swallowed thickly","released a breath","emotions I couldn't name",
  "let out a breath I didn't know I was holding","palpable","unspoken",
  "little did I know","that's when I realized","nothing would ever be the same",
  "everything changed","the truth was","I had no idea","in that moment",
  "on the record","I'd like that noted","I found out later",
  "hold space","safe space","trauma response","emotional labor","check in with","gaslighting",
  "manhood","womanhood","her heat","made love","his hardness","tightness","petals",
  "a muscle worked in his jaw","pulse quickened","stomach flipped","clenched his jaw",
  "arithmetic","load-bearing"
)

$regex = @(
  '\bnub\b','\bpearl\b','\bmath\b','\bpricing\b','\bvelvet\b','\bher sex\b','\bbud\b',
  '\bI file\b','\bfiled\b','\bfiling\b','\bunpack\b','\bvalid\b','\bnavigate\b','\bmember\b',
  '\bflower\b','\bessence\b'
)

$hits = 0
foreach ($p in $literal) {
  $m = Select-String -Path $file -Pattern ([regex]::Escape($p)) -SimpleMatch
  foreach ($h in $m) { $hits++; "BANNED  '$p'  line $($h.LineNumber)" }
}
foreach ($p in $regex) {
  $m = Select-String -Path $file -Pattern $p
  foreach ($h in $m) { $hits++; "CHECK   $p  line $($h.LineNumber)  ->  $($h.Line.Trim())" }
}
if ($hits -eq 0) { "clean" } else { "$hits flagged" }
```

`$regex` entries are **CHECK**, not BANNED — each has a legitimate use (*staff member*, *nip it in the bud*, *lotus flower*, *valid* in dialogue, a literal *velvet* curtain). Read the line before cutting.

### Signature-word census

```powershell
$t = Get-Content $file -Raw
$w = ($t -split '\s+').Count
foreach ($s in @('door','threshold','key','lock','translate','language','owe','inherit')) {
  $n = ([regex]::Matches($t, "(?i)\b$s")).Count
  if ($n -gt 0) { "{0,-12} {1,3}   ({2:N1} per 10K)" -f $s, $n, (10000 * $n / $w) }
}
```

Chapter-level spikes are fine. Track the **book-level** total against §8a.

### Do-not-strip guard

Run before any cleanup pass, so an over-eager edit doesn't remove Kent's actual voice.

```powershell
foreach ($s in @('and yet','somehow','a part of me','a mixture of','a beat','shiver',
                 'arousal','folds','breath hitched','heart hammered','butterflies','jaw ticked')) {
  $n = ([regex]::Matches((Get-Content $file -Raw), [regex]::Escape($s))).Count
  "{0,-16} {1}" -f $s, $n
}
```

These should be **present**. A chapter with zero hits across the whole list has probably been over-sanitized.
